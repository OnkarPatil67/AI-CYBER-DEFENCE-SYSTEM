# 🛡️ AI Cyber Defence System

An AI-powered cybersecurity platform that combines phishing email detection, behavioral anomaly detection, and real-time threat intelligence monitoring. The system leverages Natural Language Processing (NLP), Machine Learning, DistilBERT, and Isolation Forest algorithms to identify cyber threats and suspicious user activities in real time.

## 🚀 Features

* Phishing Email Detection using DistilBERT
* Behavioral Anomaly Detection using Isolation Forest
* Real-Time Threat Intelligence Monitoring
* Dynamic Risk Scoring System
* Security Alert Generation
* Login Activity Monitoring
* SOC-Style Dashboard
* NLP-Based Email Analysis
* Live Cyber Threat Visualization

## 🏗️ System Architecture

1. Email Input & Analysis
2. DistilBERT-Based Phishing Detection
3. User Activity Monitoring
4. Anomaly Detection Engine
5. Threat Intelligence Processing
6. Risk Score Calculation
7. Alert Generation & Dashboard Visualization
